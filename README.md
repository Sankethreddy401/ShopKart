# ShopKart Full-Stack

Frontend and backend are combined into one project folder.

## Structure
- frontend/ — React/Vite ShopKart UI
- backend/ — Node/Express/MongoDB API

## Run
Open two terminals in this folder.

Terminal 1:
`npm.cmd --prefix backend install`
`npm.cmd --prefix backend run dev`

Terminal 2:
`npm.cmd --prefix frontend install`
`npm.cmd --prefix frontend run dev`

The frontend UI code is preserved from the supplied ShopKart frontend, and the backend is preserved from the supplied ShopKart backend.
